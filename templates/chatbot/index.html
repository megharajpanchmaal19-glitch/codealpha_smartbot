About This Project

A basic rule-based chatbot developed using HTML, CSS, JavaScript, Python Django, and MySQL.

🎯

Rule-Based Engine

Pattern recognition and keyword analysis built with clean, modular Python in chatbot_logic.py, ensuring deterministic and reliable responses.

🐍

Django Backend

Robust Django 4.2+ application handling RESTful JSON endpoints, session creation, CSRF security tokens, and comprehensive error validation.

🐬

MySQL via XAMPP

Persistent storage using MySQL inside XAMPP. User queries and bot replies are chronologically archived with session-level isolation.

🎨

Modern Vanilla UI

Engineered purely with HTML5, CSS3, and modern Vanilla JavaScript Fetch API. Zero third-party bloat, ensuring maximum performance and clarity.
